# CS-330-Comp-Graphic-and-Visualization

This repository contains my final 3D Scene project and Design Decisions document for CS 330. These artifacts demonstrate my work with OpenGL, 3D modeling, lighting, textures, camera movement and interactive scene development.

## Reflection

### How do I approach designing software?

I approach software design by first identifying the project requirements and breaking the work into smaller,manageable parts. For this project, I planned scene layout,selected objects to model and considered how lighting, textures and camera controls would create the intended environment. I then created a design that organised the scene into reusable components instead of treating every object as a separate problem.

Working on this project strengthened my ability to plan visual and technical details together. I learned that design decisions such as object placement, scale, color, lighting and camera position affect both  the appearance and usability of a 3D scene. I followed an iterative process: create a basic scene, test it, improve individual objects and refine the overall composition. This approach can be used in future projects by creating a clear plan early while remaining flexible enough to improve the design through testing and feedback.

### How do I approach developing programs?

I develop programs by building and testing one feature at a time. In my 3D scene, I first created basic shapes and transformations before adding textures, lighting, materials and camera controls. I used reusable functions and structured code to make the program easier to read, update and debug.

Iteration was important throughout the milestones because each stage revealed areas that needed adjustment. For example, I refined object sizes, positions, lighting settings and textures after viewing scene during execution. My approach to development evolved from focusing mainly on getting code to work to also considering organisation, maintainability and the user's visual experience. I learned that frequent testing and small improvements are more effective than trying to complete every feature at once.

### How can computer science help me in reaching my goals?

Computational graphics and visualisation gave me practical experience with mathematical transformations, rendering, textures, lighting and interactive programming. These skills help me better understand how software can represent information and  create realistic visual experiences. They can support my future education by strengthening my problem-solving skills and understanding of programming concepts.

Professionally, these skills can be applied to software development, user-interface design, simulation, gaming, virtual environments, data visualisation and other technology fields. This course showed me how computer science combines creativity with technical problem-solving and it gave me experience developing a complete project from planning through refinement.
